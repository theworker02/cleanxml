# cleanxml

Clean numeric xml values, ranges, and human-readable units.

**Site:** https://theworker02.github.io/cleanxml/

## Install / run

```bash
git clone https://github.com/theworker02/cleanxml.git
cd cleanxml
node src/cli.js
node --test
```
